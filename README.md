# 📚 Student Smart Planner

A simple and interactive web application designed to help students efficiently manage academic tasks, track study progress, view schedules on a calendar, and receive due-date reminders.

---

## ✨ Features

* **Task Management:** Add, update, and organize assignments, projects, and exams.
* **Progress Tracking:** Monitor your study progress and completion rates.
* **Calendar View:** Keep track of important academic dates and deadlines in one place.
* **Reminders:** Get timely alerts for upcoming due dates so you never miss a deadline.

---

## 🚀 Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Styling:** CSS
* **Storage:** LocalStorage
